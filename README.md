# Triangle Geometry Core & Interactive Visualizer

Интерактивное графическое приложение и вычислительный модуль для анализа геометрических свойств треугольника. Реализует математическую валидацию фигур, расчет параметров в реальном времени и интерактивную манипуляцию вершинами на холсте (Canvas).

## 🛠 Стек технологий
- **Язык:** C#
- **Фреймворк:** WPF (.NET / XAML)
- **Архитектура:** Модульное разделение UI-событий, Canvas-рендеринга и математических вычислений

## ✨ Ключевые возможности
- **Интерактивный холст:** Перетаскивание вершин треугольника мышью (Drag & Drop) с динамической перерисовкой граней и координат.
- **Геометрические расчеты:** Вычисление длин сторон, периметра, полупериметра и площади (формула Герона).
- **Математическая валидация:** Проверка неравенства треугольника и определение его типа (остроугольный, прямоугольный, тупоугольный, равнобедренный, равносторонний).
- **Чистый код:** Безопасная обработка граничных условий координат и событий мыши (MouseMove, MouseDown, MouseUp).
